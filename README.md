# Cukiernia Wrocławska — strona demonstracyjna

Zwykły HTML, CSS i JavaScript. Bez instalowania pakietów, backendu i budowania.

## Uruchomienie lokalne
Otwórz `index.html` w przeglądarce.

## GitHub Pages
1. Utwórz repozytorium lub użyj istniejącego.
2. Wrzuć `index.html`, `style.css`, `script.js` i folder `images` do głównego katalogu repozytorium.
3. Wejdź w Settings → Pages.
4. W Source wybierz **Deploy from a branch**.
5. Wybierz branch **main** i folder **/(root)**.
6. Zapisz i poczekaj na publikację.

Nie dodawaj własnego workflow ani szablonu Next.js. GitHub wykonuje standardową publikację Pages; ewentualne blokady konta trzeba rozwiązać w GitHub.

## Edycja
Teksty: `index.html`. Wygląd: `style.css`. Menu i formularz demo: `script.js`.
Zdjęcia można podmienić w `images`, zachowując nazwy plików; zaktualizuj też opisy `alt`.
Formularz tylko pokazuje komunikat — nie wysyła ani nie zapisuje danych.
